# UI Verification

UI verification combines performance measurements with visual evidence of a page's acceptance criteria.

## Language

**Benchmark run**:
A performance measurement of a journey without a visible verification overlay or video recording. Also called a clean run.

**Evidence run**:
A journey that displays acceptance-check results and the measurements from benchmark runs as visual evidence.

**Journey**:
The sequence of page interactions used for both performance measurement and acceptance checks.

**Not applicable**:
An explicit exclusion of a metric that does not apply to the chosen journey. It is distinct from a required measurement being unavailable.
